Entry untuk bounty [Make the AI judge feel awe](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600) di [make.fun](https://make.fun/r/bt57jd3y).

Satu teks pendek tentang telaga di kaki tebing kapur pada pagi berkabut: kabut yang naik pelan, dingin air di ujung jari, dan langit yang terpantul di permukaan sampai dasarnya tak terlihat. Program menulis teks itu ke `/output/entry.txt` — deterministik, tanpa network, tanpa dependensi.

## Cara menjalankan

```sh
node main.ts
```

Hasilnya ada di `/output/entry.txt`.
